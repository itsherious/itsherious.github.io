// about-me

It Started With a Mod

Hey there! I'm Khanh Huy — a full-stack developer whose origin story begins in 2018, tinkering with Java plugins for a Minecraft server that maybe twelve people ever played on. Watching a block of code turn into a working game mechanic was the spark. I never really stopped chasing that feeling.

Today I design and build full-stack products — from pixel-perfect React front-ends to backend systems that hold up under real traffic. I care about clean architecture, honest documentation, and shipping things that actually work, not just things that demo well.

Off the clock, I'm usually exploring a new framework, contributing to open source, or — yes — still occasionally booting up Minecraft for "inspiration."
